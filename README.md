# Calculator

A calculator in plain HTML, CSS, and JavaScript. There is no framework and no build step.

| File | Role |
| --- | --- |
| `index.html` | Buttons and display. The page title is "calculator" |
| `calculator.css` | Layout |
| `claculator.js` | The click handler and the arithmetic. The filename is spelled that way on purpose in this repo; `index.html` loads it |

## View it

Open `index.html` in a browser.
